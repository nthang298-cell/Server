This is a simple WinForms client added to the workspace.
Build and run with:
  dotnet build ClientGUI\ClientGUI.csproj
  dotnet run --project ClientGUI\ClientGUI.csproj

Features:
- Connect to UDP server, send/receive raw messages
- Export chat to .docx

Note: This is a minimal GUI to get started; you can extend it to use the same protocol as the console client.
